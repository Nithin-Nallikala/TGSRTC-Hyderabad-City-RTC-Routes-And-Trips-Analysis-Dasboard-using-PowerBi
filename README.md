# TSRTC Hyderabad City RTC Routes and Trips Analysis Dashboard

## Description
Developed a Power BI Transportation Analytics Dashboard using SQL, Excel, Power Query, and DAX to analyze Hyderabad city bus operations. Built interactive KPI reports and visualizations to identify travel patterns, route performance, and service coverage trends.

## Tools Used
MySQL, Excel, Power BI, Power Query, DAX, Data Transformation, Dashboard Development

## Project Overview

1. Built an interactive Transportation Analytics Dashboard using MySQL, Excel, and Power BI to analyze Hyderabad city bus operations and service performance.
2. Processed and analyzed nearly 1 million transit records covering routes, trips, stops, schedules, and service calendars.
3. Designed a relational data model and connected multiple GTFS datasets to create a single source of truth for reporting and analysis.
4. Developed KPIs and visualizations to identify peak travel hours, busiest routes, depot-wise trip distribution, and service coverage patterns.
5. Applied SQL, data cleaning, data transformation, and DAX techniques to convert raw transit data into meaningful business insights.
6. Strengthened skills in Data Analytics, Data Modeling, Power BI, SQL, Dashboard Development, and Business Intelligence Reporting.
